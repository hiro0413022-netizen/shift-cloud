## 0. これから作るもの

ピエゾが打撃を検知したら、赤外LEDを **20µsだけ、決められた間隔で4回**光らせる箱。

部品は5点だけです。LED・MOSFET・ゲートドライバ・コンデンサ・Pico 2。
難しいのは部品選びではなく、**20µsの立ち上がりを鈍らせない配線の作法**です。
そこだけ、以下で丁寧に書きます。

**LEDが4個しかない段階Aなら、右の直列（LED5〜8）を省いて左だけにしてください。**
抵抗は 3.0Ω のまま、ピーク電流は 3A になります。

### ゲート駆動

```
  Pico 2                IR4427PBF (DIP-8)
  GP15 ──────┬──── 2 INA        OUTA 7 ──┬── 10Ω ──→ MOSFET の G
             └──── 4 INB        OUTB 5 ──┘
                                            ★2回路を並列にして駆動力を倍に

              6 VCC ── 12V（別途 12V を作るか、24Vから三端子で落とす）
              3 GND ── ロジックGND
              ※ VCC の足元に 0.1µF を1個（パスコン）

  G と S の間に 10kΩ を入れる（電源投入時の誤点灯防止）
```

**ゲートドライバの電源は 12V** です。MOSFET のゲートは 10〜12V で駆動すると
最も速く、完全に開きます。Pico の 3.3V を直接ゲートに入れてはいけません
（IRLB3034 はロジックレベル対応ですが、3.3V では開ききらず発熱します）。

24V 1本で済ませたい場合は、24V→12V の三端子レギュレータ（7812 等）を1個足してください。

### ピエゾ入力

```
              ┌──── 1MΩ ──── GND        （電荷の逃げ道。無いと張り付く）
              │
  ピエゾ ─────┼──── 10kΩ ────┬──── GP14（Pico）
   7BB-27     │              │
              │         ツェナー5.1V×2
              │         （逆向きに直列）
              │              │
             GND            GND
```

ツェナー2個を**背中合わせ**にすると、±5.1V を超えた分だけを逃がします。
ピエゾは叩くと数十Vを出すので、これが無いと Pico が壊れます。

## 2. 絶対に守る2つのこと

### ★ 1. MLCC（10µF積層セラミック）を、LEDのすぐ横に置く

6Aを20µsで立ち上げるとき、電流は**いちばん近いコンデンサから出ます。**
電解コンデンサは容量は大きいものの内部抵抗（ESR）が高く、この速さには追いつきません。

```
必要な ESR = 許容降下 0.3V ÷ 6A = 50mΩ 以下
電解コンデンサ単体では届かない → MLCC を5個並列（実効 数mΩ）で補う
```

**MLCCをLEDから10cm離すと、配線のインダクタンスで効果が消えます。**
LEDの＋端子から2cm以内、できれば直付けしてください。
ここを省くと「光っているのに暗い」という、原因の分かりにくい失敗になります。

### ★ 2. GNDを2つに分け、1点だけで繋ぐ

```
  パワーGND：MOSFETのソース ─ コンデンサの−端子
  ロジックGND：Pico ─ ピエゾ ─ ゲートドライバのGND

  この2つは、コンデンサの−端子の1箇所でのみ接続する
```

6Aの戻り電流がロジックGNDを通ると、そこに電圧が生じて
**ピエゾが勝手に反応したり、Pico がリセットしたりします。**
「たまに2回光る」「打っていないのに光る」の原因はほぼこれです。

## 3. ブレッドボードで作ってよい範囲

| 部分 | ブレッドボード | 理由 |
|---|---|---|
| Pico・ピエゾ入力・ゲートドライバの入力側 | **可** | 電流が小さい |
| コンデンサ 〜 LED 〜 MOSFET 〜 GND | **不可** | 接触抵抗とインダクタンスで立ち上がりが鈍る |

**パワー側は最初からユニバーサル基板に、太い線（AWG18以上）で組んでください。**
電流の通る輪（コンデンサ→LED→MOSFET→GND→コンデンサ）の**面積を最小に**するのが要点です。
配線を長く引き回すと、そこがコイルになって電流の立ち上がりを妨げます。

## 4. 組み立ての順番（各段階で必ず確認する）

### 段階1：Pico だけで波形を出す

LEDもMOSFETも繋がず、**GP15にオシロを当てるだけ。**

```
1. Pico 2 に MicroPython を書き込む
2. strobe.py を main.py という名前で Pico に転送
3. シリアルで繋いで `T` を送る
4. GP15 に 3.3V のパルスが4回出るのを確認
```

**ここで確認すること：**
- 発光の長さが 20µs か（`W 20` で設定した値）
- 間隔が指示どおりか（`V 50` なら 64mm ÷ 50m/s ＝ **1.28ms**）

`strobe.py` の中の `_OVERHEAD = 5` は、PIOの前後処理にかかるサイクル数の見積もりです。
**オシロで実測して、ずれていたらこの数字を直してください。** 1サイクル＝6.7ns です。

### 段階2：ゲートドライバとMOSFETを繋ぐ（LEDはまだ）

LEDの代わりに **3.0Ωの抵抗だけ**を24Vとドレインの間に入れ、
抵抗の両端をオシロで見ます（8A流れるので、**数秒以内で切り上げること**）。

**確認すること：**
- 立ち上がりが **200ns以下**か
- 波形が振動（リンギング）していないか

振動する場合はゲート抵抗 10Ω を 22Ω に上げてください。
鈍い場合は 4.7Ω に下げます。

### 段階3：LEDを繋ぐ

まず **1直列（4個）だけ**、電流を絞って（抵抗を 6.0Ω にして 1.5A）点けます。
スマートフォンのカメラを向けると、**850nmは白っぽい点として写ります**（肉眼では薄赤）。
これが最も簡単な発光確認です。

問題なければ抵抗を 3.0Ω に戻し、2直列目を足します。

### 段階4：ピエゾを繋ぐ

マットの下に両面テープで貼り、**軽く叩いて光るか**を確認します。

- 反応しない → 10kΩ を 1kΩ に下げる、またはコンパレータを足す
- 素振りや隣の振動で光る → `LOCKOUT_MS` を伸ばす、閾値回路を足す

実機では打球の強さでバラつくので、**LM393 コンパレータ＋半固定抵抗**で
閾値を調整できるようにするのが、いずれ必要になります。

### 段階5：カメラと合わせる

段階1（再帰反射方式）なら、カメラの露光を長め（1/60秒）に開けっぱなしにして、
その間にストロボを自走させます。**1枚の中に4つのボールが写れば成功です。**

## 5. 数字の根拠（確認用）

| 項目 | 式 | 値 |
|---|---|---|
| 抵抗値（24V・4直列） | (24 − 4×3.9) ÷ 3A | 2.8Ω → **3.0Ω** |
| ピーク電流 | 3A × 2並列 | **6A** |
| 抵抗の発熱 | 3²×3.0×20µs×4発 | 2.2mJ／打 → **1Wで充分** |
| 必要な容量 | 6A×20µs×4 ÷ 0.5V | 960µF → **1000µF×2** |
| 必要なESR | 0.3V ÷ 6A | **50mΩ以下** |
| ゲート立ち上がり | 130nC ÷ 1.2A | **約108ns** |
| デューティ比 | 80µs ÷ 3秒 | **0.0027%** |

デューティ比がほぼゼロなので、データシートのパルス定格（3A、tp≤800µs、D≤0.005）の
内側に大きく収まります。**放熱器は要りません。**

## 6. 安全について

- **850nmは肉眼にほとんど見えません。** 光っていないように見えても光っています。
  組み立て中、LEDを覗き込まないでください
- ストロボはボールの高さ（床から10cm前後）から水平に発光します。
  打つ人の顔は1.6m前後なので直射しませんが、**製品化の際は IEC 62471
  （光生物学的安全性）の評価が必要**です
- 24Vは感電の危険はありませんが、**6Aの短絡は配線を溶かします。**
  電源を入れる前に必ずテスターで短絡がないか確認してください

## 8. まだ決まっていないこと

- `_OVERHEAD = 5` の実測値。**オシロで合わせること**
- ピエゾの閾値。実打で決める。コンパレータが要るかどうかもそこで判断
- 集光レンズの有無と配光角。光量の実測次第
- カメラとの同期方法。段階1は「露光開けっぱなし」で回避しているが、
  取りこぼしが数%出る。製品化では外部トリガ付きカメラに移行する
