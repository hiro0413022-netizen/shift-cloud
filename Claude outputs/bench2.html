比べる

インパクトの瞬間を合わせて並べています。撮影位置が違うと見た目の角度も変わるので、 同じ場所で撮ったもの同士で比べてください。

保存したスイング

映像はこのパソコンの recordings フォルダーに残ります。外には出ません。
保存するのはスイングのところだけを切り出した動画（webm）です。 それでも 容量はすぐ埋まります。いらないものは消してください。
骨格データ（landmarks.json）は映像よりずっと軽く、将来コーチAIに渡すのはこちらです。 容量が苦しくなったら、映像だけ消して骨格を残す、という残し方ができます。

カメラの割り当て

機器名がそのまま出ます。同じ名前が3つ並ぶので、映像を見て決めてください。
レンズを手で覆うと、どれがどれか分かります。選ぶと保存され、次回もこの割り当てで開きます。

役割で取れる指標が変わります。 正面=肩の傾き・頭の動き／側面=前傾角・起き上がり／右斜め=回転量・Xファクター

この画面について

取り込みも骨格推定もブラウザの中で完結しています。Python 側は設定の保存だけです。
MediaPipe の本体とモデルはこのパソコンから配っているので、通信がなくても動きます。
指標の計算式は Python 版とまったく同じものを移してあり、同じ入力で同じ数字が出ることを確認しています。

画角と明るさは、要求の出し方で決まります。
1280×720 を頼むと、1920×1200 のセンサーの一部だけが切り出され、広角レンズの画角が失われます。
fps を高く頼むと、自動露出はその間隔に収まる長さまでしか露光できません （120fpsなら最長1/120秒、30fpsなら1/30秒で4倍明るい）。
Windows のカメラアプリが明るく広く見えるのは、1920×1200 の30fpsで開いているからです。
