# RUNBOOK — ビジター予約の受付（Reserve OS）現場手順書

対象: 申込対応をする店舗スタッフ（GOLF WING）。
URL: https://shift-cloud-reserve-os.vercel.app

---

## 1. しくみ（30秒で理解）

- お客様は日時を**即確定できません**。「候補日時を第3希望まで＋事前ヒアリング」を送ってくる**申込型**です
- 申込が入ると**シフトアプリ（Shift Cloud）の「やること」に店舗共通タスク**として出ます — 店の誰かが対応すれば全員から消えます
- 日程を確認して**スタッフが確定**して初めて予約成立です
- **確定を押した瞬間に、member-osの受付台帳（一時利用者名簿）にその日の行が入ります**（2026-08-29〜）。来店当日はタブレットに**お名前・電話・メールが入った状態**で開くので、お客様に同じことを二度書かせません
- 見送り・キャンセルにすると台帳からも自動で下がります（来店打刻済みの行は残ります）

## 2. 申込が来たら（当日中に折り返す）

1. シフトアプリの「やること」に出た申込タスクを開く（第1〜3希望・電話・メール・詳細URLが載っています）
2. 希望日時にフィッティング対応できるスタッフがいるか・枠が空いているかを**目視で確認**
3. 対応可の日時が決まったら Reserve OS の申込詳細を開き、**確定**の操作 → お客様へ確定連絡
4. どの希望日時も難しい場合は、**電話かメールで代替日を相談**してから確定する（勝手に見送りにしない）
5. 確定/見送りにするとシフトアプリのタスクは自動で完了になります

## 3. やってはいけないこと

- **24時間以上放置しない**（放置は本部のGENESISに「未対応の申込」として警告表示されます）
- ダブルブッキング防止のため、確定操作の**前に**必ずカレンダー・他の確定済み申込を確認
- お客様への返信は**GOLF WINGのメールアドレス**から（個人アドレスを使わない）

## 4. 公開URLの案内

- 一覧画面の上部に**公開URLのコピー**ボタンがあります（例: `/reserve/shaft-fitting`）
- 公式LINEのリッチメニュー・トークでの案内に使えます

## 5. 未対応の申込はどこに出るか（2026-08-29〜）

- **店舗ダッシュボードの一番上**に「折り返し待ちのフィッティング申込」として常に出ます（何日経ったかのバッジ・電話番号・申込詳細へのリンク付き）
- 「やること」にも出ますが、あちらは**申込を受けた日のマス**なので、日が経つと奥に入ります。**上の常設パネルが正**です
- 確定するとパネルから消え、代わりに**当日の「本日のフィッティング」**に並びます

## 困ったとき

| 症状 | 対処 |
|------|------|
| 申込タスクがシフトアプリに出ない | Reserve OSの申込一覧を直接確認。出ていなければ古川さんへ |
| 確定メールが届かないと言われた | 迷惑メールフォルダを案内。それでも無ければメールアドレスの誤記入 → 電話で連絡 |
| お客様から日時変更の連絡が来た | 申込詳細のメモに経緯を残し、新しい日時で確定し直す |
| 誤って確定/見送りにした | 慌てなくてOK。古川さんへ連絡（状態は戻せます） |
