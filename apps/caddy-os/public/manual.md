# RUNBOOK — キャディ派遣管理（Caddy OS）現場手順書

対象: 派遣の記録・請求書発行をする担当者。
URL: https://caddy-os-omega.vercel.app

---

## 1. ログインする

- Shift Cloudと同じID・パスワード
- 「アクセス権がありません」→ キャディ権限（use_caddy）が未付与。古川さんへ

## 2. 月のシフトを組む（推奨の流れ / DECISIONS #140）

**この順番でやれば、同じことを二度入力する場面はありません。**

1. **希望を集める** — キャディ本人に配った提出URL（`/s/...`）から入力してもらう。
   まだ配っていない人は【設定】→委託先の行→「提出URLを発行」→コピーしてLINEで送付。
   LINEや電話で聞いた分は【出勤可否】で代理入力してもOKです（どちらも同じ場所に入ります）。
2. **カレンダーで組む** — 【シフトカレンダー】で日付をタップ。
   その日に○/△を出しているキャディだけが候補に並ぶので、ゴルフ場とキャディを選んで**「仮で追加」**。
   金額（売上・委託料・交通費）はマスタから自動で入ります。
3. **確定する** — 組み終わったら「この日をまとめて確定」または「今月の仮をまとめて確定」。
   1件ずつ確定・仮に戻す・取消もできます。
4. **確定した瞬間に、あとは全部自動です**:
   - 【キャディ台帳】に勤務日・ゴルフ場・料金が載る
   - 【ゴルフ場提出】にその月の派遣一覧が出る
   - 【請求書】【支払】の対象になる
   - 本部の財務（月次PL）へ集計される
5. **ゴルフ場へ送る** — 【ゴルフ場提出】→ゴルフ場ごとに「CSV」。
   Excelでそのまま開けます（書式はゴルフ場ごとに【設定】で変えられます）。

> **仮のままだと出ません。** 仮は下書きなので、請求にもCSVにも財務にも入りません。
> 【ゴルフ場提出】の上に「仮のままの割当が N 件あります」と出たら、カレンダーで確定してください。

### キャディ本人の画面（`/s/...`）

- 日付をタップするたび ○（出られる）→ △（要相談）→ ×（出られない）→ 未回答 と変わり、その場で保存されます
- 今月＋2ヶ月先まで入力できます。**過ぎた日と、派遣が確定した日（青い「勤」）は本人からは変更できません**
- URLが漏れたときは【設定】の「再発行」を押してください。古いURLはその瞬間に使えなくなります

## 3. 派遣を記録する（1派遣=1行・まとめて入力したいとき）

1. 【派遣一覧】→ 一括入力グリッドで入力（Excelのように**Enterで次の行**へ。日付・取引先は前の行から引き継がれます）
2. **取引先を選ぶと売上単価が自動で入る**／**委託先を選ぶと委託料が自動で入る**
3. **社員（林さんなど）の派遣は委託料0のまま**にする — 人件費は給与側で計上されるため、ここに金額を入れると二重計上になります（入れようとしてもエラーになります）
4. 登録すると通し番号は日付順に自動で振り直されます（手で採番しない）

## 4. 請求書を発行する（月締め後）

1. 【請求書】→ 取引先を選ぶ → 対象月を選ぶ
2. 明細（キャディ業務料 × 日付 × 人工数 × 単価）・消費税・合計が自動計算されます
3. 内容を確認して**ブラウザの印刷 → PDF保存**（そのまま送付できます）
4. 締め日は取引先マスタの設定（月末締め/20日締め）に従って自動で切られます

## 5. 出勤可否カレンダー

- 【出勤可否】で委託先キャディごとに ○可 / △要相談 / ×不可 をクリックで登録（空欄=未回答）
- **委託先キャディはShift Cloudのシフト・勤怠には載せない**（社員ではないため。載せると給与＝二重計上になります）

## 6. マスタ管理

- 取引先（ゴルフ場）: 単価・締め日を登録。**単価改定したらマスタを先に直してから**派遣を入力
- 委託先キャディ: 委託料単価を登録。新しい委託先はまずマスタ登録（未登録のまま台帳に書かない）

## 7. この事業の注意（担当者が知っておくこと)

- 薄利事業です。**月商80万円を切ると赤字**（固定給が損益分岐点。ダッシュボードに常時表示）
- 売上・粗利は自動で本部の財務（fin_entries）へ集約されます — 手で財務側に入力しない

## 困ったとき

| 症状 | 対処 |
|------|------|
| 請求書の金額が台帳と合わない | 対象月の派遣行の「人工数・単価」を確認（1行の入力ミスがそのまま請求に出ます） |
| 社員に委託料を入れたい | 入れない（給与と二重計上）。交通費も給与側です |
| 委託先が選択肢に出ない | マスタ未登録。先に委託先マスタへ登録 |
| 誤入力を消したい | 行の削除は論理削除。消した理由をメモに残す |
| ゴルフ場提出CSVに人が足りない | その割当が**仮のまま**です。シフトカレンダーで確定してください |
| キャディが提出URLを開けない | 【設定】で「再発行」→新しいURLを送る（古いURLはその時点で無効になります） |
| CSVをExcelで開くと文字化けする | 本システムのCSVはBOM付きUTF-8です。ダウンロードしたファイルをそのままExcelで開いてください（メモ帳等で保存し直すと化けます） |
| 確定した派遣を直したい | カレンダーで「仮に戻す」→直す→もう一度確定。取り消すだけなら「取消」（履歴は残ります） |
