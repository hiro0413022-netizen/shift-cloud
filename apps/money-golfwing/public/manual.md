## 1. ログインする

- Shift Cloudと同じID・パスワード
- 「アクセス権がありません」→ お金管理の権限が未付与。古川さんへ
- **店舗を選んでから作業**（PCは左上、スマホは右上。1店舗だけの人は選ぶ必要はありません）

## 2. 毎日やること（店舗スタッフ）

1. **売上を入れる**: 上から順に ①いつ・どなたに ②払い方 ③何を売ったか を埋めて【この売上を追加】
   - よく売れる物は**「よく売れるもの」のボタン**を押すと商品と金額が1回で入ります
   - 金額は **定価 →（値引き）→ 個数** を入れれば、金額(税抜)・**お支払い額(税込)** まで自動で出ます。値引きは**マイナス**で入力
   - 自動の数字は上書きできます（端数調整など）。上書きした欄はそれ以降自動で動きません
   - 1人のお客様が何点も買ったときは【まとめて入れる】
   - 入れた分は同じ画面の下「今日入れた分」で確かめて、まちがいは【直す】
   - 過去の分・Excel書き出しは【一覧・直す】タブ。お客様名を押すと**そのお客様の購入履歴**が開きます
2. **レジのお金 ＞ 出し入れの記録**: 現金の売上以外で、レジからお金を出した・入れたとき（両替・備品の現金払い・返金など）
3. **レジのお金 ＞ レジ締め**: 閉店時にお札・小銭の**枚数**を入れると、合計と「帳簿との差」がその場で出ます。**差があってもそのまま保存**（心当たりをメモに書く。数字を合わせに行かない）

## 売上を表で見る（Excelのように）

- 【売上を見る】→【表で見る（Excelのように）】
- 「よく使う表」の【パーソナル × 担当（今月）】を押すと、担当ごとに **件数・回数・金額・1回あたり** が出ます
- 縦（行）・横（列）・商品名の言葉・期間を変えれば、どんな表でも作れます（例: 横を「月」にすると月ごとの推移）
- 件数＝お会計の数、回数＝個数の合計（2回分を1回のお会計で入れたら 1件・2回）
- 【Excelで開く（CSV）】でそのままExcelに持っていけます

## 3. レシート・書類（請求書・領収書・レシート）— まず撮って残す

1. 【経費を入れる】→【レシート・書類】→【＋ レシート・書類を残す】
2. スマホで撮った写真かPDFをアップロード（種別・金額・発行元は**わかる範囲で**。空欄OK）
3. 後からAIが日付・金額・発行元を読み取って空欄を補完します（人の入力は上書きされません）
4. **紙はこれまでどおり保管**（電子帳簿保存の原本ルールは従来運用のまま）

## 4. 本部だけの作業

- **カード・口座取込**: AMEX・尼崎信金のCSVをアップロード → 自動仕分け。未仕分けはダッシュボードに残るので月内に振り分ける
- **売上分析**: 事業別・カテゴリ別・支払方法別。**「予測」バッジ付きの月会費は暫定値**（口座振替の実績が届くと自動で置き換わる）
- **売上台帳の月次取込**: `npm run import:sales -- --month=YYYY-MM --apply`（Claude作業。台帳Excelが締まったら依頼）

## 5. やってはいけないこと

- 現金の差額を**入力で無理に合わせない**（差額はそのまま・メモに理由）
- 台帳由来の月会費を「月会費」カテゴリで手入力しない（月会費予測が消えて売上が激減します。窓口分は「月会費(窓口)」）
- 証憑の削除は論理削除のみ。**ファイルの物理削除はしない**（電帳法配慮）

## 困ったとき

| 症状 | 対処 |
|------|------|
| アップロードが失敗する | ファイルが大きすぎる可能性（8MB上限）。写真を縮小して再試行 |
| CSVが取り込めない | 銀行/カード会社のサイトから**加工せず**ダウンロードし直す（Excelで開いて保存すると形式が壊れます） |
| 金種棚卸で差額が出た | そのまま登録し、メモに状況を記載。続くようなら古川さんへ |
| 数字がダッシュボードと合わない | 月会費「予測」バッジの有無を確認。それでも不明なら古川さんへ |
