# RUNBOOK — レッスンカルテ（Lesson OS）現場手順書

対象: レッスンを担当するコーチ。
URL: https://lesson-os.vercel.app （ホーム画面に登録しておくと楽です）

---

## 1. ログインする

- Shift Cloudと同じID・パスワード
- 「アクセス権がありません」→ レッスン権限（use_lesson）が未付与。古川さんへ

## 2. レッスンの流れ（1人あたり1〜2分の記録）

1. レッスンノート（生徒一覧）から生徒をタップ（いなければ【＋生徒を追加】— **名前だけでOK**）
2. 大きな【📹 スイングを撮影する】を押す → **その場でカメラが開きます**（ファイルを選ぶ操作はありません）
3. 撮り終わったら同じ画面でクラブ・飛距離・メモを入れて【この動画を登録する】— ここで完了です
4. 動画の下に**コーチからのアドバイス**を書いて送信
5. 良いスイングは【☆ベストにする】（生徒ごとに1本）

> カメラアプリで先に撮ってある動画を入れたいときだけ、下の「動画ファイルから取り込む」を開いてください。

## 3. 映像を使った指導

- 一覧には**1コマ目の静止画がすでに出ています**。押せばその場ですぐ再生されます（動画の中身は押すまで読み込まないので、電波が弱くても一覧は軽いままです）
- 描画やコマ送りを使うときだけ【✎ 描画・フェーズ・スロー】を押してください
- 動画を開くと**描画ツール**が使えます: 直線／円／フリーハンド（4色）・スイングプレーン／前傾ガイドのワンタップ表示・コマ送り・スロー再生（0.25x/0.5x）。【描画を保存】で次回も表示されます
- 「比較再生」タブで**過去と現在**、または**お手本スイングと並べて同時再生**できます

## 4. 進捗（レッスン目標）

- 「進捗」タブで9項目（グリップ〜フィニッシュ）の達成度をスライダーで更新→【登録】
- レーダーチャートは生徒の共有ページにも表示されます。**目標の見える化は継続率に直結**します

## 5. 生徒への共有（アプリ不要）

1. カルテ右上の【🔗生徒へ共有リンク】→ URLをコピー → **LINEで生徒に送る**
2. 生徒はそのURLで自分専用ページ（進捗レーダー・レッスン記録・アドバイス・お手本）をいつでも見られます
3. URLが漏れた場合は【共有を停止する】→ 再発行

## 6. お手本スイング

- 上部メニュー「お手本スイング」でコーチの見本動画を登録。比較再生と生徒ページに表示されます

## 7. スイングを撮る（撮影モジュール）

1. 生徒のカルテ →【📹 スイングを撮影する】
2. スマホを固定する（画面のガイド線は 2026-08-22 に廃止しました）
   - **後方（DTL）**: 後ろ足のつま先の延長線上・**腰の高さ**・ターゲットラインと平行
   - **正面（フェースオン）**: スタンスの中央に正対・**腰の高さ**
   - 共通: 人物は9:16の枠の中に、**頭の上に余白（トップでクラブが切れない）・足元にボール**が入るように
3. 秒数（5/8/12秒）と**カウント（なし／3秒）**を選び、**赤いシャッターボタン**を押す
   - **カウント「なし」（初期値）＝押した瞬間に録画開始**。人に押してもらうとき・自分で打つ直前に押すときはこちら
   - **カウント「3秒」＝3・2・1のあと自動で開始**。スマホを置いてから構えに戻る時間がほしいときはこちら
   - どちらも**時間がきたら自動停止**。選んだ設定はその端末に記憶されます（2026-08-26）
4. 撮れた動画を確認 → **同じ画面で**クラブ・飛距離・メモを入れて【この動画を登録する】
   - 下までスクロールして別の「登録」を押す必要はありません（2026-08-22に一本化）
   - クラブや飛距離はあとから直せます。**まず登録してしまってください**
   - iPhone/iPad などその場再生に対応しない端末では**1コマ目の静止画**が出ます。登録すれば一覧から普通に再生できます

> 毎回**同じ画角**で撮ると、比較再生とフェーズ比較が効きます。

> **マイクを塞がないでください。** 打球音からインパクトの位置を自動で見つけています。

## 8. スイングの位置にジャンプする（フェーズ移動）

再生画面の上に **アドレス／テークバック／トップ／切り返し／インパクト／フォロー／フィニッシュ** のボタンが並びます。押すとその位置に一発で飛びます（◀▶で前後のフェーズへ）。

- 位置がズレていたら【✎ 位置を調整】→ 動画をその位置で止めて、直したいフェーズのボタンを押す →【フェーズを保存】
- 昔に登録した動画は【⚡ 自動推定】を押せば後からマークできます
- **生徒の共有ページでも同じジャンプ・スロー再生・コマ送りが使えます**（生徒は位置を変えられません）

## 9. スイングを解析する（骨格・クラブ軌跡・スイングプレーン）

再生画面を開いて【🦴 解析する】を押すと、動画をコマ送りで読み取って
**骨格・クラブヘッドの軌跡・スイングプレーン**を動画に重ねます。

1. 動画の【▶再生・描画をひらく】→「スイング解析」の行の【🦴 解析する】
2. 進捗が100%になるまで待つ（8秒の動画・30コマ/秒で30秒ほど。**初回だけ**モデルの読み込みで余分にかかります）
3. 以降は同じ動画を開けば**すぐ出ます**（結果は保存されます）
4. 【骨格】【クラブ軌跡】【プレーン】のボタンで、それぞれ出し入れできます

### 体の数字（そのコマの値）

| 表示 | 意味 |
|------|------|
| 肩の傾き / 腰の傾き | 画面上での肩ライン・腰ラインの傾き |
| ねじれ | 肩と腰の差。トップでの上体と下半身の分離の目安 |
| 前傾 | 背骨の傾き。アドレスからフィニッシュまでどれだけ起き上がったか |
| 頭のブレ | **アドレスを基準にした頭の移動量**（肩幅を100%とした割合。フェーズの「アドレス」を設定すると出ます） |

### スイングプレーンの数字

| 表示 | 意味 |
|------|------|
| プレーン角 | 基準にした線の、水平からの角度 |
| トップ / 切り返し | そのフェーズでクラブがプレーンからどれだけ離れていたか |
| バック最大 / ダウン最大 | 上げるとき・下ろすときの最大の離れ |

**＋がプレーンより上（スティープ側）、−が下（シャロー側）**。数字はクラブ長を100とした割合です。
基準線は**アドレスのシャフト線**を自動で引きます。ズレていたら、線ツールで引き直して
【✎ この線をプレーンにする】を押してください（**手で引いた線が常に優先**され、解析し直しても残ります）。

### 大事な注意

### 三脚は要りません（前回に重ねて撮ってください）

撮影画面の【👻 前回に重ねる】を押すと、**その生徒の前回のスイングが薄く重なって表示されます。**
人と打席の位置が重なるように立ち位置を合わせてから撮れば、前回と同じ画角になります。
三脚を毎回据える必要はありません。

解析結果の上に **「📷 正面72° ・体の大きさ 61%」** のように出るのが今回の画角です。
前回と近い数字なら、角度もそのまま比べられます。

> **数字の読み方**：カメラ1台なので、角度は「画面に映った見た目の角度」です。
> **頭のブレ・プレーンからの離れ（％）は体の大きさで割ってある**ので、
> 撮影距離が変わっても比べられます。一方で**角度は立ち位置が変わると変わります**。
> 他人と比べるためではなく、**同じ生徒の前回との差**を見るために使ってください。

> **オレンジの実線が「映像から実際に取れた」ヘッド、青い点線が「腕の向きから推定した」ヘッド**です。
> クラブが止まる瞬間（トップ）や、暗い背景に重なったコマは映像からは取れません。
> そういうコマは、前後の確かなコマと腕の向きから補っています（腕とシャフトの角度は急には変わらないため）。
> 補えないほど空いているところは、**線を引かずに飛ばします**。滑らかにつないで嘘をつかないためです。
> 「実測◯コマ・推定◯コマ」が解析結果の下に出ます。

> **スローモーションで撮った動画もそのまま取り込めます。**
> 【⬆登録】のファイル選択から入れてください。解析コマ数は 30 のままで構いません
> （スロー動画はコマとコマの間でクラブがほとんど動かないので、システム側で自動的に
> 少し離れたコマと見比べています）。

> **うまく取れないとき**：「◯/◯コマ検出」が半分を切っていたら撮影条件です。
> **全身（足先から頭まで）が入っていること・逆光でないこと・背景と服の色が近すぎないこと**を確認してください。
> クラブ軌跡だけ出ないときは、**手元とクラブが画面から切れていないか**を見てください。

## 9.5 レッスンの会話からメモを作る（会話メモ）

カルテの「**会話メモ**」タブで、レッスン中の会話を録音すると、AIがメモの下書きを作ります。

1. **お客様に必ず説明して、同意をいただいてください。**
   「レッスンの記録のために会話を録音します。メモを作ったら音声は消します」
2. 画面のチェックを入れる → 【🎙 録音を始める】
3. レッスンが終わったら【■ 録音を止めてメモを作る】
4. 数分待つと下書きが出ます。**内容を確認して直してから【確認して保存】**

### 守っていること

- **同意のチェックを入れないと録音ボタンは押せません。**押した時刻と先生の名前が記録に残ります
- **音声はメモができた時点で自動的に消えます。**残るのは要約と、先生が直した本文だけです
- 文字起こしも【文字起こしを消す】でいつでも消せます
- **AIが書いたものはそのままカルテに出ません。**先生が保存したものだけが記録になります

### コツと注意

- **録音中は画面を消さないでください。**消えると止まる端末があります
- **30分を超えるレッスンは、前半・後半で2本に分けて**録音してください
- スマホが遠いと声を拾えません。**先生がポケットに入れる／Bluetoothのピンマイクを使う**と精度が上がります
- お客様が録音を望まないときは、録音せずに手で書いてください（これまでどおり使えます）

## 10. トラックマンの数値を取り込む（写真を撮るだけ）

1. 生徒のカルテ →「**計測**」タブ →「ファイルを選択」（スマホならその場でカメラが開きます）
2. トラックマンの **1ショットの計測画面** をまっすぐ・明るく撮る
3. AIが数値を読み取り、**全項目が編集できるフォーム**に載ります
4. **違うところを直してから**【この内容で保存】。読めなかった項目は空欄なので、必要なら手で入れてください

> AIは入力の下書き係です。保存されるのは**コーチが確認したあとの数値**なので、誤読があってもデータは汚れません。
> 単位（m/s・mph・yd・m）は写真に写っているものをそのまま持ちます。**勝手に換算しません。**
> 写真がぼやける・数字が切れていると読めません。読めなかったときは手入力で保存できます。

## 11. FRANKの会員とカルテ（自動）

- FRANKで**入会が確定した時点でカルテが自動でできます**（コーチが登録する必要はありません）
- **退会するとカルテは一覧から消えます**。記録が消えたわけではなく、生徒一覧の「退会者も表示」にチェックを入れれば開けます
- 予約システム（member-os）のカレンダーで予約をタップ →【レッスンカルテを開く】でその人のカルテが直接開きます

## 12. データの持ち出し

- 生徒一覧右上の【⬇CSV】でレッスン記録をいつでもエクスポートできます（データは人質になりません）

## してはいけないこと

- 動画を**生徒本人以外に見せない・SNSに上げない**（共有は本人へのURL送付のみ）
- 動画の削除は間違えて撮った場合のみ（上達の記録が消えます）

## 困ったとき

| 症状 | 対処 |
|------|------|
| アップロードが終わらない | 電波を確認。200MB超の動画は分割 or 短く撮り直し |
| 動画が再生できない | 再読み込みして再度【▶再生】（再生リンクは30分で切れる仕様） |
| 共有ページが見られないと言われた | 共有を停止していないか確認→必要なら再発行してURLを送り直す |
| 生徒を間違えて登録した | 古川さんへ（統合・削除できます） |
