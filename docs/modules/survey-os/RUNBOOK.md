# RUNBOOK — アンケート（Survey OS）現場手順書

対象: アンケートを配る・結果を見るスタッフ。
URL: https://survey-os-mu.vercel.app

---

## 1. ログインする

- Shift Cloudと同じID・パスワード（管理画面のみ。**回答者はログイン不要**）
- 「アクセス権がありません」→ アンケート権限（use_survey）が未付与。古川さんへ

## 2. アンケートを配る

1. 一覧で対象アンケートの**公開URL**（`/s/アンケート名`）をコピー
2. 公式LINE・掲示POP・口頭案内などで共有（回答は**匿名**。名前は集まりません）
3. 公開中のものだけ回答できます（下書き・終了は自動で受付停止）

## 3. 結果を見る

- 一覧 → 対象アンケート → 【結果】
- 単一/複数選択: 件数と割合
- **順位付け（ドラッグ並べ替え）**: 「ボルダ得点（0-100）」と「平均順位」の両方で表示 — 高得点・小さい順位ほど支持されている
- 自由記述: 全文一覧（そのまま会議資料に使えます）

## 4. アンケートを新しく作る・締める

- **新規作成・設問変更は古川さん経由**（現状はAI/データ投入で作成。編集画面での作り込みは順次拡張中）
- 締切: 一覧から状態を「終了」に変更（公開URLは自動で受付停止表示）

## 5. 運用ルール

- 同じアンケートを**期間を変えて再利用しない**（比較できなくなる。新しく作る）
- 回答のお願いは「1分で終わります」など所要時間を添えると回答率が上がります
- 個人を特定する設問（氏名・連絡先）は入れない（匿名設計のため）

## 困ったとき

| 症状 | 対処 |
|------|------|
| 回答者が「回答できない」と言う | アンケートが「公開」状態か確認。URLの打ち間違いが多いのでLINEでURLを直接送る |
| 回答が反映されない | 結果画面を再読み込み。それでも出なければ古川さんへ |
| 設問を間違えて公開した | すぐ「終了」にして古川さんへ（回答済みデータは消さずに残す） |
