# AIカルテナレッジ — オンラインレッスン・モード（RaRa LESSON）

2026-09-15 / #242 / migration 0182（適用済）

小川うらら（RaRa）さんの **LINE公式「RaRaLESSON 会員様専用」でのオンラインレッスン** に特化した画面。
AIカルテナレッジ（swing-cortex）の中で、**テナント単位で画面を切り替える**（`sc_settings.mode = 'online'`）。
他のテナント（GOLF WING・FRANK・津・デモ）は `coaching` のままで何も変わらない。

## 運用の流れ

```
LINEに会員から動画とメッセージが届く
 → 受信箱（返信待ちが長い人から上）→ 会員を開く
   ① 届いたメッセージ（最後の返信より後の文章が自動で入る／貼り付けも可）
   ② 動画を見て気づいたこと（箇条書き・音声入力可）
   ③ 返信の方向（長さ・褒め多め・継続・次の課題・感覚を聞く・遅れのお詫び）
 → 【返信文をつくる】→ 下書きを直す（区切り線・動画・定型文・絵文字・AIで直す・戻す）
 → 【コピーする】→ LINEに貼って送る → 【LINEで送った】＝履歴・課題・動画の使用回数が残る
```

受信箱の右の「Quick Reply」にメッセージを貼ると、本文の名前から会員を推定してそのまま返信づくりへ進める。

## 決めたこと

1. **LINEへは送信しない。** 出すのは下書きだけ。会員様専用OAはGENESISの `gn_line_channels` に繋がっておらず、繋いでも月の送信上限（#line-monthly-limit）を食う。貼るのは本人。
2. **AIは動画を見ていない。** 動きの指摘は ② のメモに書かれたことだけ。メモが空なら動画の中身を断定しない（プロンプトで禁止＋画面にも明記）。
3. **URLは作らせない。** 参考動画は `sc_online_videos` から候補（メモを重く・会員の文を軽く見た上位10本）を渡し、出力のURLが候補に無ければ `cleanDraft` が消す。
4. **言い回しは本人の過去の返信から。** 全会員の「相談→返信」の組（約1,800組）から2-gram×希少度で似た相談を4件＋その会員の直近2件を例として渡す。10分キャッシュ。
5. **プランのルールは設定画面で文章として持つ。** レギュラー＝スイングのみ（実際の返信に「レギュラープランではスイング以外のアドバイスを行えませんが」がある）／プレミアム＝コースマネジメント等まで。
6. **下書きと確定文の両方を残す**（`sc_online_replies.ai_draft` / `final_body`）。どこを直したかが後から分かる＝将来の口調合わせの材料。
7. **書きかけは端末に自動保存**（localStorage・3日）。画面を移っても消えない。
8. **トーク履歴は LINE Official Account Manager の CSV をそのまま取り込む。** `(member_id, fingerprint)` の一意索引で何度入れても二重にならない。同じ秒に同じ本文（動画を続けて送る）があるので出現順の番号も指紋に混ぜる。
9. **会員名は LINE の表示名から分解**（`☆辻子　曜(レギュラー)` → 名前・プラン・印）。印（☆ ⚠️）は本人の運用メモなので捨てずに `mark` に残す。

## 画面

| パス | 中身 |
|---|---|
| `/online` | 受信箱（返信待ち・今月の返信数・会員数／絞り込み／Quick Reply／会員追加） |
| `/online/[id]` | 会員ごとの返信デスク（PC・iPad横＝左に会員メモ＋トーク、右に返信づくり／スマホ・iPad縦＝タブ） |
| `/online/videos` | 動画ライブラリ（サムネイル・タグ・使用回数・コピー・編集） |
| `/online/templates` | 定型文（追加・編集・並べ替え・コピー） |
| `/online/settings` | 口調・プラン別ルール・署名・文字数上限／CSV取り込み |

デザイン: 公式サイト（online-golflesson.com）のチャコール `#313131`×白を基調に、シャンパンゴールドの差し色。英字見出し（Inbox / Videos …）＋日本語の小見出しはサイトの構成（About 専属の… / Price 基本的な…）に合わせた。`.theme-rara` で既存の `--color-*` を上書きするだけ。

## 実装の置き場

- `src/lib/online/line-csv.ts` … CSVの読み取り・表示名の分解・動画URLの抽出（純関数・`tests/swing-cortex-online-csv.test.ts`）
- `src/lib/online/reply.ts` … プロンプト・返信例の選択・動画の順位・出力の掃除（純関数・`tests/swing-cortex-online-reply.test.ts`）
- `src/lib/online/import.ts` … 取り込み（DBクライアントを引数で受ける＝初期投入スクリプトからも同じ処理）
- `src/lib/online/data.ts` … 読み取り・`requireOnlineActor`
- `src/app/(main)/online/online-actions.ts` … サーバーアクション（全部 `assertOnlineActor` → company_id で絞る）
- `(main)/layout.tsx` が mode を見て `OnlineShell` に切り替え。`/` と `/library`（ログイン後の着地）は online なら `/online` へ。

## 残り・次の候補

- 会員の「いまの課題」は空。返信をつくると AI が更新案を出し、チェックで反映される。
- 受信箱は会員ごとに1クエリ（8名なら問題なし。50名を超えたらまとめて引くRPCに）。
- LINE Webhook で自動受信する形（会員様専用OAを `gn_line_channels` に登録）にすれば貼り付けが要らなくなる。送信はしない方針は維持。
