## 2. 予約のしくみ（お客様は全部Webで完結）

- **体験**: サイト（frankgolf.jp）で日時を選ぶと**即確定**。打席は自動割当。スタッフの折り返しは不要
- **打席**: 会員がサイトから30分単位で予約（プラン別の上限は自動チェック）
- **レッスン**: 藤田プロ・穴田君の公開枠から会員が予約 → カルテが自動で作られる
- **電話・店頭で受けた予約**: member-os「予約（姫路）」から入力（Webと同じ台帳に入る＝二重予約は起きない）
- 予約したお客様には**確認メールと前日リマインダー**が自動で届く（メールがある場合）

### スタッフがやること

1. 朝: 当日ボードで今日の体験・予約・レッスンを確認
2. 来店したら member-os で「来店」に変更（無断キャンセルは「無断欠」）
3. 店頭・電話の予約はその場で member-os に入力（口約束・メモ書きにしない）

## 3. 体験のお客様が来たら（入会率50%が目標）

1. 受付 → カウンセリング（ゴルフ歴・目標を聞く。**100切り/90切りなどの目標を必ず聞く**）
2. 打席へご案内 → 体験レッスン（TrackManのデータを見せる。「データが残る」が売り）
3. ご入会のご案内: プラン表（ライト9,800／レギュラー13,800／マスター19,800 税抜）
   - その場で入会 → サイトの「Webで入会」か店頭タブレットで申込 → 本部が承認 → 会員番号発行
   - 会員番号が出たら **サイトの予約ページから月会費のカード登録**をご案内（Square自動課金）
   - **申込の時点ではカード情報は取りません**（申込フォームに支払方法の選択肢もありません）。
     月会費はクレジットカードのみ＝「申込 → 承認 → 会員番号のメール → 会員ページでカード登録」の順です。
     お客様に「今カードを登録したい」と言われても、会員番号が出る前は登録できません（画面で弾かれます）
4. 入会に至らなくても連絡先を記録（後日フォローは本部のAIが起案）

## 4. 会計（毎日）

- **Square導入後**: 店頭会計（物販・ビジター・レッスン単発・体験オプション）は**すべてSquareでレジ打ち**。
  現金もSquareに打てば、売上・現金出納・本部の日次レポートまで**全部自動で記録**されます。手書き台帳と写真報告は廃止
- **Square導入まで**: 店頭決済台帳に記録 → 閉店時に台帳の写真をスタッフLINEへ（従来どおり）
- 月会費はカードで自動課金（Square）なのでレジ操作は不要。※店頭レジで会員の月会費を打たないでください（二重請求になります）
- **入会金 11,000円（税込）**: Webでカード登録した方は自動請求されるのでレジ不要。店頭払いの方だけレジの「入会金」ボタンで徴収。クーポン適用の方（申込時に入力済み・member-osの備考に出ます）は無料
- **休会**: member-os で「休会」にすると自動課金が止まります。**休会費 2,200円（税込）はレジの「休会費（1か月）」で毎月徴収**。復帰したら member-os で「復帰」（自動課金が再開）
- **プラン変更**: member-os の会員一覧「プラン変更…」から。当月の差額は自動でカード請求されます（カードが無い方は画面に出る金額を店頭で徴収）
- レジ締め: 閉店時に現金実査 → Squareのレジ締め（差異があれば翌朝の朝連絡に自動で出ます）
- 物販の在庫・仕入れは藤田プロが管理

## 5. レッスン（藤田プロ・穴田君）

- 枠の公開・変更は Lesson OS「FRANK」から（打席指定枠は打席予約から自動でブロックされる）
- レッスン後は**その場で記録**（record_note）と**次回への申し送り**（handover_note）を入力
  → 次回予約時に前回の申し送りが自動表示されます
- 体験レッスンも同じ画面で記録（入会後にカルテが引き継がれる）
