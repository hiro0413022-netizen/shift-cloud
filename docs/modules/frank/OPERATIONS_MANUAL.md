## 4. 会員登録の流れ（お客様が入会するとき）

1. 店頭 or HPの入会フォームからお客様情報を入力（店頭ならタブレットでスタッフが補助）
2. 申込は自動で本部（Genesis）に届き、**承認されると会員登録完了**
3. 会費の支払い登録（8月に自動課金システム導入予定。それまでは店頭決済で受領し台帳へ）
4. 会員プラン: ライト9,800／レギュラー13,800／マスター19,800／法人39,800・59,800（税抜）
5. 初回来店時: 会員証（LINE友だち登録）・利用ルール説明・打席の使い方・TrackManの起動

## 5. 会計の流れ（毎日）

1. 店頭での現金・PayPay等の受領はすべて**店頭決済台帳**に記録（金額・内容・会員名）
2. 閉店時にレジ締め: 現金実査 → 台帳と一致確認
3. 日次報告: 台帳を提出（当面は写真をスタッフLINEグループへ→古川さん承認。システム化後はタブレットから直接入力）
4. 物販（ボール・グローブ等）は藤田プロが在庫管理・仕入れ判断
