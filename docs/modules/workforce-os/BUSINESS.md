## 業務ルール

### シフト希望
- スタッフは時間を手入力しない。管理者作成のテンプレートをワンタップ選択
- メモ欄あり（例:「17時以降なら残れます」「宝塚勤務希望」）
- 募集期間（対象月・締切）は管理者が設定

### 雇用形態と給与
- `employment_type`: 社員 / アルバイト / 業務委託 / レッスンプロ
- 時給は履歴管理（`staff_wages`、有効開始日つき）。昇給しても過去の給与計算は不変
- 給与見込み = 実働分 × 時給 + 交通費 + 手当 − 控除（MVPは時給ベース。月給者は表示のみ）
- 丸め: 実働1分単位記録。計算時丸めは会社設定（デフォルトなし）

#### レッスン手当（パーソナルレッスン）— DECISIONS #105

- **パーソナルレッスン（25分）1件 = 2,000円**。全スタッフ共通の単価（スタッフ別マスタは持たない）
- **入力しない**。算出元は Money OS の売上台帳（`mon_sales_lines` の商品名「パーソナルレッスン（25分）」）で、
  「集計を実行」のたびに `payroll_allowances`(kind='personal') へ自動で入れ直す。手で直しても次の集計で上書きされる
  → **直すのは money-os の売上明細（担当プロ・件数）**
- 件数は `qty` の合計。`item_category='返金'` はマイナス計上（手当がマイナスになる場合は0で止める）
- 誰にどう払うかは担当プロ名簿 `mon_pros.payout_mode` が決める
  - `payroll` … 給与の手当（井殿・卜部・榎本・福原）
  - `outsourcing` … 業務委託費に上乗せ。**給与明細には載せない**（安東さん 2026-06〜）。
    「集計を実行」で money-os の外注費（`mon_expense` category='外注' / source='lesson_allowance' / 勤務月の月末計上）へ**自動計上**する（#106）。
    実際に振り込んだら money-os「カード・口座取込」＞「支払の消込」でその出金と結ぶ（#108）。
    結ぶまでは発生分だけが計上され、結んだ後も二重にはならない
  - `none` … 対象外（古川さん＝月給・役員報酬。レッスンを担当しても手当を付けない）
- 売上台帳の担当プロは自由記述の姓なので、表記ゆれは `mon_pros.aliases` で名寄せする（例: 「春馬」→卜部さん、末尾の「プロ」は自動で落とす）
- 紐付け・支払区分・別名の編集は **money-os の「設定」＞「給与連携（パーソナルレッスン手当）」**（#106）
- 担当プロ未設定 / 名簿に無い名前の売上は取り込まず、給与画面に警告として出す（黙って0円にしない）
- コンペ・ラウンドレッスン・フィッティング紹介料・交通費実費は従来どおり手入力（自動取込は personal のみ）

### 勤怠
- 遅刻 = 確定シフト開始より打刻が遅い / 早退 = 終了より早い / 残業 = 終了超過
- 打刻漏れ = シフトあり＆打刻ペア不成立 → アラート
- 修正は理由必須、修正前後と修正者を保存、元打刻は不変
